# D2 地图数据源评估：高德（2026-09-30）

> 本文记录高德作为 D2 地图候选的数据源、接入条件与失败行为，不是独立开发任务。实施顺序与验收只以 `docs/AGENT-ROADMAP.md` 的 S1-4、O1-2/3 为准。2026-10-02 已完成 S1-4 本地验收：合成地图初始化和一次公开地点合成坐标转换成功；费用与许可未独立核实，尚未授权公开部署或购买服务。

## 需求边界

- S1-4：在真实地图上展示本轮机位与已校验的候选机位；点击标记和列表选择同一机位，坐标、朝向和题材与结构化计划一致。
- O1-2/3：按赶场计划顺序展示机位与路段。只有路线服务给出可核验的道路几何时才标为道路路线；手工通勤估算只可画“直线示意”。路线文字列表在地图失效时仍完整可用。
- 不从地图底图、屏幕像素或地名反向推断精确机位；无坐标或坐标系未知的旧机位不落点。

## 官方能力与约束

## 隐私与失败行为

地图和路线请求会向高德发送精确机位坐标。D2 必须先向用户说明这一点，由用户主动触发在线地图；规划、导出和离线回放不能强制加载高德。浏览器只通过 POST 提交当前用户的收藏机位 ID，本地后端从档案核验坐标系、取出精确坐标后再向高德转换，避免坐标进入浏览器转换请求或本地访问日志的 URL 查询串；不得在应用日志打印原始坐标或 Key。坐标不进入分享 URL，用户机位仍遵守本地最多六位小数、默认导出不含坐标的已确认规则。

地图脚本、配额、转换或路由失败时显示具体原因，并保留机位列表、时间窗和路线文字结果。没有真实路线几何时，可展示标为“直线示意”的自有坐标连线，但不得给出道路拐弯、精确到达时间或导航承诺。固定 Fake 仅用于离线测试和明确标记的演示。

## 2026-10-02 本地验收结论

- 公开城市中心的 JS 地图初始化到达 `MAP_COMPLETE_WITH_SURFACE`；独立 Web 服务 Key 对一组公开地点合成 WGS84 坐标的转换返回有效 GCJ-02 结果。仅执行这一笔坐标转换实测，未向高德发送用户收藏机位坐标；调用不会自动进入门禁。
- 已接入手动加载的 JS API 地图、本机同站点 JS 样式代理及按当前用户收藏机位 ID 解析 WGS84→GCJ-02 转换的 POST 边界；Web 转换与 JS 代理凭据分离。固定路径代理不开放浏览器 GET 坐标转换，不缓存高德响应。离线/失权时保留机位列表与失败原因。
- 控制台截图确认个人开发者及上述当时额度和用量，但没有证明费用/超额扣费策略或长期许可。小北明确无需为本地开发继续确认费用和许可；S1-4 的本地验收因此完成。真实用户坐标仅在用户主动加载地图时按已批准的方案外发；公网部署和购买服务仍需单独审批。道路几何仍属 O1-2/3。
