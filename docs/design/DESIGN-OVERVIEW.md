# LightTrail 设计概览

> 2026-10-06职责整理。原始方案、组件理由及历史确认措辞已 [归档](../archive/audit-20261006/docs/design/DESIGN-OVERVIEW.md)，未删除。当前规范见 [FRONTEND-SPEC](FRONTEND-SPEC.md)。

视觉目标：摄影场景的暗色背景、暖色强调与克制卡片，帮助用户快速辨认结论、行动与依据。信息沿Home/D1/D2/D3/D4/M1六页组织，记忆与来源贯穿流程。已有原型与令牌作为参考，工程真实状态由FEATURES说明。

[静态原型](delivery/lighttrail-prototype.html)包含演示数据，不连接真实决策服务，也不证明当前六页所有交互已可用。旧文档“三页现状”“纯前端覆盖90%”“用户认可”描述来自历史稿，本次未找到全部原始确认依据，不扩张为对当前产品的批准。

保留的设计理由：暗色适合摄影使用情境；语义图标+文字避免只依赖色彩；行动层先于过程细节；地图/照片应辅助具体决策；来源、缺失和冻结标记帮助核对。未经校准的概率/区间与真实流程Fake不应为满足原型外观而保留。

当前用户验收先服务“今晚火烧云是否值得去”。保存恢复、异常、过期、取消和外传告知属于产品交互，不是实现细节清单。新增组件与信息架构需要说明用户问题，主要产品/架构选择待确认，排期只在 [路线图](../AGENT-ROADMAP.md)。
