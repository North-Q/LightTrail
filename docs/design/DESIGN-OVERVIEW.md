## 3. 设计决策说明（为什么这么做）

### 3.1 产品定位 → 设计形态

LightTrail 差异化是「给决策，不只是给数据」。设计上把「决策」与「依据」做成**双层信息结构**：

- **决策层**（视觉焦点）：大号三态卡「去 / 再等等 / 放弃」、倒计时、置信度主值；
- **依据层**（可展开、永不缺失）：概率依据条、置信度区间 + 依据列表、四步推理链、数据来源标签、相似历史命中。

这直接回应目标用户「被信任」的核心诉求——每个决策都能追溯到数据与推理，而界面保持克制的暗夜极简，不被术语劝退。

### 3.2 设计系统选型（彩格调）

从 71 套品牌设计系统中，推荐 **Linear 结构基底 + Claude 暖琥珀基因的定制融合**：

| 来源 | 借用什么 | 为什么 |
|------|----------|--------|
| Linear | 暗色工具质感：近黑底、发丝级边框、精密克制、密度控制 | 摄影规划需要工程级精确性（时间线/参数/调度） |
| Claude | 暖陶土琥珀点缀、编辑气质、AI 信任感、依据/来源表达 | 琥珀金与「黄金时刻/光」母题同源；AI 决策附依据的成熟表达 |

融合成本最低（同源深色基底），一致性最高。C 案（Warm Editorial）仅作编辑感补充参考。

### 3.3 品牌母题：「黄昏渐变」

- 品牌名「光迹」= 暗夜 + 光的轨迹；
- 色彩系统以 **琥珀金（#E8A23B）→ 冷蓝（#5F8DF2）** 构成黄昏渐变两端，仅用于品牌时刻（brand-mark、today-card 顶边）与天象时间线（dusk 渐变带）；
- Slogan：「给决策，不只是给数据」，全站文案直接、无营销腔。

### 3.4 可解释性（M2）的界面化落地

PRD 的 M2 可解释性在原型中被做成**强制性设计规范**：

- 置信度指示器**禁止单一数字**，必须三层结构：主值 + 区间条 + 依据列表；
- 语义色**永不单靠颜色**（色盲友好）：绿/黄/红必配图标 + 文字；
- 页脚「数据与依据 · 解释中心」集中展示数据源清单。

### 3.5 移动端策略（专项强化）

- **桌面优先**：规划类操作（时间线、地图、参数联动）依赖大屏；
- **移动端特化**：临场决策发生在户外现场，D3 决策页做现场模式（大按钮）、依据折叠为底部抽屉、导航收进汉堡菜单、触控目标 ≥44px、天象时间线横向滚动；
- 双视口（390×844 / 360×780）12 张截图实测核查通过。

## 4. 质量审查结果（严过审）

**总体结论：PASS（品牌级交付水准）**

| 维度 | 评分 | 要点 |
|------|------|------|
| 设计哲学 | 4/5 | 黄昏渐变母题贯穿，「给决策」可信感在 D3 结构化立住（5 层支撑） |
| 视觉层次 | 4/5 | D3 12 列网格、tabular-nums 数值对齐、导航契合拍摄旅程 |
| 执行质量 | 4/5 | 令牌落实忠实；2 项 P1（动效超限/对比度）已修复 |
| 特异性 | 5/5 | 曝光三角真实联动、500/NPF 公式、S5M2+契卡14mm 真实语境、可执行处方 |
| 克制 | 5/5 | 三色+三语义调色板、无 emoji、无营销空话、示例数据诚实 |

**Anti-Slop 门控：通过**（无彩虹渐变、无虚假统计、无 AI 套路卡片、对比度达标）。

**修复记录**：P1×2（动效 600→240ms、`--text-muted` #5C6B7F→#7382A0 过 WCAG AA）+ P2×4（焦点环、留白填充、CTA 弱化、dusk 母题呼应）+ 移动端 JS 缺陷×3 + 移动端专项强化×8 项。

- 全部动态数据通过 ID 绑定，后续接真实数据前端零改动（换 `fetch` 即可）。

## 6. 后续推进建议

### 6.1 工程接入（按数据成本渐进）

1. **天文数据**（最低成本，可立即接）：Skyfield/astropy 离线计算日出日落/月相/银河窗口；
2. **气象数据**：Open-Meteo/和风/彩云，云量/火烧云概率；
3. **地图/交通**：高德/百度，机位朝向/赶场 ETA；
4. **多模态 AI**：D4 复盘、D1 照片反推；
5. **个人记忆**：M1 相似命中、偏好归纳。

> 架构推荐已随 `docs/architecture.md` v2.0 更新为：**FastAPI 薄服务层 + SSE 事件流 + SPA 前端**（单进程部署，串行约束天然满足；详见解剖 v2.0 §2.8 Web 交互层 / §2.9 并发与会话模型）。前端工程的落地任务为路线图 v2.0 的 **E7-5**——以本原型为 spec，优先接入「天文 + 气象」打通决策闭环，术语「trace 即 UI」即本原型右栏轨迹面板的产品化来源。

### 6.2 产品迭代

- 原型已为 PRD v0.2 的 D1-D4 + M1/M2 提供了完整视觉与交互基线，可直接作为工程实现的高保真参照；
- 建议下一步：以本原型为 spec，落地 FastAPI + Web UI 前端骨架，优先接入「天文 + 气象」打通决策闭环。
