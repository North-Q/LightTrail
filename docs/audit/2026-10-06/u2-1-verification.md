# U2-1 等待取消与请求预算验收

日期：2026-10-06；main / 4b04b81 + 已有 U1 与文档未提交增量。仅本地离线替身，未调用真实 API、外发个人数据、提交或发布。U1 验收记录与归档不改写。

## 复现与修复证据

修复前 `tests/test_request_budget.py` 首轮 **4 failed / 2 passed**：concurrency=1 的排队者取消后，持有者退出，active=0 但唯一许可不可获取；自定义 0.12/0.34 秒配置未传入生产客户端，仍为 30/120；真实 OpenAI SDK 配合内存 HTTP 替身，持续 429、503 各产生 **9 次底层发送**。400、401 原有一次发送行为保留。浏览器反例首先失败于 D3 缺少“停止等待”按钮。

- 限流保留同一个 `threading.BoundedSemaphore`；异步排队改为非阻塞尝试与 10ms 可取消等待，不再遗留 acquire 线程。获取成功到 finally 建立之间没有 await；已进入请求在取消、超时、异常退出时归还许可。该等待不保证 FIFO；原有 queue_position 仍是“当前在途数”，不是精确排队长度。
- `build_client` 传入配置超时；同步 SDK 和每个事件循环的异步 SDK 使用显式 `httpx.Timeout`。读取值用于 read，连接值用于 connect/write/pool；非正或非有限配置被拒绝。同一门面使用唯一限流器，按 loop 复用 HTTP 连接池，防止后台同步入口与 Web 复用绑定另一 loop 的连接。
- SDK `max_retries=0`，外层 `_MAX_ATTEMPTS=3`，包含首次发送，即最多两次重试。状态重试只允许 429、500、502、503、504；连接/超时类瞬时错误保留重试，普通参数错误与非重试 HTTP 状态不重复发送。退避在许可外，退避取消后没有后续尝试；调试日志显示 SDK 尝试序号。
- D1–D4 操作使用组件生命周期内的 AbortController 与请求身份。停止立即撤销旧请求回写资格；卸载自动 abort，旧事件、缓存写入与 finally 均被拦截。D1 参考图也可停止；D4 停止后不提交剩余照片；D2 计划、赶场及导入导出分别清理。SSE pending read 会响应 abort，释放 reader 和监听器；done 与提前断流保持独立语义。
- 自建客户端随应用关闭，异步宿主 await `ApplicationServices.aclose()`，CLI 用 `close()`；注入客户端由调用方管理。关闭前宿主应先结束请求，在事件循环仍运行时释放连接池。

## 预算与取消边界

“最多三次”针对**一次模型 acall/chat 的底层尝试**，不表示一次摄影管线只调用三次模型。排队不算发送，最大两次退避合计 4 秒；连接和读取超时是传输阶段上限，读取可能按响应块计时，**不是整条管线或整次 SSE 的总墙钟时限**。本批不引入新并发配置或全局截止时间。

直接取消异步 acall 会停止本地等待/传输并归还许可；这也不能证明供应商停止计算或不计费。取消 SSE 的 worker 协程只取消对 `asyncio.to_thread` 的等待，已运行同步线程仍可能继续模型或工具调用。离线 pump 反例明确观察到：SSE worker 已取消，底层线程尚未完成，直到替身释放才结束。没有新增端到端取消协议，页面统一提示“已停止等待……不能确认服务端或供应商请求已取消”。不承诺撤销已提交的写操作或费用。

## 人工验收

使用已启动的本地 Vite，打开 [U2-1 手动离线页](http://127.0.0.1:5173/tests/u2-1.html?manual=1)。它只提供合成机位、合成照片和延迟响应；浏览器存储使用 `u2-demo.` 前缀，不读写个人档案或历史。全部 API 被内存替身拦截，替身故意忽略 abort，便于观察迟到响应。

1. 在决策页输入“今晚火烧云是否值得去”并提交，点击“停止等待”；按钮立即恢复，提示不能确认底层已取消。
2. 点击“返回最近请求的迟到结果”，旧卡不得出现；再次提交则保持新请求的等待状态。
3. 请求等待中点击“离开当前页”，再返回迟到结果；回到页面后应无旧结果。灵感对话、参考图与复盘上传可用同样方式验收；照片仅选择自行生成的空白测试图片。
4. 规划页选择“合成机位”与日期，运行后停止；旧规划不能覆盖停止提示。复盘多张合成照片停止后，不继续发送剩余照片。

重新启动预览或执行自动检查：

```powershell
npm --prefix frontend run dev -- --host 127.0.0.1
npm --prefix frontend run test:u2-1
npm --prefix frontend run check:u2-1-ui
```

页面停止能力不等于供应商取消；无需启动真实后端。后端许可与预算证据可用项目虚拟环境运行 `python -m pytest tests/test_request_budget.py` 复核。
