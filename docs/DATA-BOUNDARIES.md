## 访问规则

- 实际连接地址必须为 loopback；Host 必须严格为 `localhost`、`127.0.0.1` 或 `[::1]`，可带合法端口。不能依赖 `X-Forwarded-Host`、`X-Forwarded-For` 获得许可；重复 Host/Origin 拒绝。不要将服务监听到公网。
- 写请求的 Origin 允许 HTTP 上述主机的 5173（Vite）、4173（预览）、8000 端口，以及当前请求 Host 的同源地址；不允许 `null`、HTTPS、公网来源、伪本地域名或其他跨端口来源。其他前端端口需显式改动 allowlist，不能自动放开任意 localhost 页面。
- 无 Origin 的本机 CLI/脚本可以访问；若带 `Sec-Fetch-Site`，仅接受 `same-origin` / `none`，Referer 若存在必须同源。跨站浏览器写请求拒绝。CORS 只负责浏览器可读性，服务端中间件在写路由前独立校验权限。
- 所有 API 的 Host/客户端边界同时限制读取；写保护覆盖档案、收藏增删、事件、会话/决策、照片、计划归档及地图转换，不仅是 JSON PUT。预检不会写数据。
- 此规则防止普通跨站写入与 DNS rebinding，不隔离本机恶意程序、浏览器扩展、被控制的允许来源或有文件权限的其他进程；本机脚本可以伪造 Origin，因此不能把该规则作为公网认证。

## 保留和删除

以实际 `LIGHTTRAIL_DATA_DIR` 为根目录，不能假定所有部署都使用仓库 `data/`：

- `users/_local/memory/profile.json`：器材、偏好、收藏机位和坐标。删除收藏只更新当前档案。
- `users/_local/memory/events.db`：确认的拍摄事件。SQLite 使用期间还可能有 WAL/SHM 伴随文件；必须先停止服务再做文件级清理。
- `users/_local/memory/semantic.json`：语义记忆与待确认内容。历史迁移文件、自建用户目录和备份需额外核对，不能只删除 `_local` 后宣称全部清理。
- `sessions/*.json`：U3 保留实际文字结果与 SpotPlan 的版本数组，包括稳定 ID/父版本、原请求、完整消息、卡、管线工具结果、trace 和时间。管线及 SpotPlan 快照可含机位精确坐标、名称、来源、EXIF 文本或其他上下文；收藏修改/删除不修改这些历史副本。旧照片入口仍有会话工作区保存，尚未全部接入版本索引。LRU 仅淘汰内存缓存，磁盘暂无自动到期删除；完整历史随版本重复保存，暂无分页或大小回收。失败或停止等待也可能已有记录；清理某用户时还须核对此公共 sessions 目录中对应 user_id 的文件。
- 浏览器 localStorage 的 `lt.session.id`、`lt.sessions`、`lt.last_card`、`lt.active_spot_id`：分别为会话标识、摘要、旧卡和机位选择。U3 另保存 `lt.saved.chat`、`lt.saved.decision`、`lt.saved.spot_plan` 的 session/result 指针；稳定链接只含 ID，不含坐标，所有读取仍由服务端检查 RequestContext 归属。清空对话入口或删除收藏不会清除所有浏览器与服务端副本。
- 照片：上传原图仅写到服务端自选临时文件，处理线程在正常完成或异常后 `finally` 删除；浏览器预览 object URL 随页面清理。停止等待不终止已运行线程，临时文件可能暂留；进程强制退出/断电等不会执行 finally，残留需部署者核查系统临时目录。本批不自动扫描或删除真实照片。

目前没有一键删除全部数据、事件单条删除或可靠的供应商撤回机制。需要清理时：**先停止服务，核对部署根目录、对应用户和文件，再只删除明确选定的本地文件；清除本站浏览器存储；另行处理手动导出、截图、备份及旧日志。** 本批没有执行任何真实用户数据清理，也没有增加清理脚本。

供应商的实际保留期限、训练用途及删除渠道尚未核实。清理本地数据不删除供应商副本；停止等待不代表撤回发送、免计费或底层已取消。未覆盖公网身份认证、磁盘加密、受控浏览器扩展和对系统级文件权限的隔离。

## U5本地反馈与撤回

D3结果反馈及本人手写经验只写本机users/{user}/result-feedback/{session}/{result}.json；绑定稳定结果ID及固定v1摘要，不复制原卡/坐标。原始反馈不自动写events/semantic；本人经验确认仅本地回看，尚未纳入Agent记忆，memory_written=false。自由文本可能自含个人信息，不保存到浏览器localStorage，不外发；未保存草稿关闭会丢失并有离开提醒。

反馈修改使旧经验确认失效；撤回反馈清空反馈及经验正文，保留ID、目标、版本、时间和最近操作摘要；撤回经验仅清其正文/确认时间并保留最小元数据，原卡及反馈保留。重新填写不复活旧经验。GET仅公开最近操作ID，内部请求摘要不下发。撤回不删除原计划，也不宣称清除本人备份/导出/截图或供应商副本。

photo_refs首版只允许空数组，非空422，无U5照片上传/EXIF/图片模型入口。既有D1/D4照片能力仍按上文独立边界；不能从U5照片接口缺失推断全应用没有照片功能。本批全部使用新合成目录，不读取或回放原真实隔离材料；原真实轮次不追加。见[U5验收](audit/2026-10-11/u5-verification.md)。
