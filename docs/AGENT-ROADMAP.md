## 4. 长期用户结果

1. **可靠单次决策**：关键数据可信、缺失可继续、参数与机会成本可解释。

3. **复盘改善下一次**：计划与实际可比较，用户认可的经验可撤回、可追溯；有数据后评估校准。
4. **更复杂的机会选择**：陌生地点、多机位赶场、光路与光污染按真实缺口引入。
5. **可复现开源交付**：安装、隐私、能力说明及维护边界清楚；托管多用户与自动提醒另设门槛。

这些是依赖关系与方向，不是日期承诺，也不要求全部做完才允许讨论早期本地开源。
