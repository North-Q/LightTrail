## 1. 引言

### 1.1 项目背景

大语言模型（LLM）在通用对话与推理方面已展现出强大能力，但在垂直专业领域的落地仍面临知识准确性、工具协同、场景适配等挑战。摄影是一个高度依赖专业知识（曝光三角、天文气象、构图法则）与实践经验（机位选择、时机判断）的场景，现有摄影 App 多以信息查询为主（如日出日落时间、星历表），缺乏从「想拍」到「拍成」全流程的智能辅助。

LightTrail（光迹）旨在将 LLM 的推理与工具调用能力应用于摄影垂直场景，构建一个覆盖拍摄前规划、拍摄中指导、拍摄后分析全流程的 AI 智能体应用。

### 1.2 项目定位

摄影助手智能体——不是信息查询工具，而是具备规划、推理、计算与多模态理解能力的主动型助手。

**核心差异化**：
- 不是「查星历表」，而是「明天凌晨适合拍银河吗？适合的话几点去、去哪拍、用什么参数」
- 不是「查天气」，而是「当前云量条件下，火烧云概率多大，值不值得去」
- 不是「修图工具」，而是「这张片子构图和曝光有什么问题，下次怎么改进」

### 1.3 项目目标

| 维度 | 目标 |
|------|------|
| 产品 | 实现四大核心功能模块的最小可用版本（MVP），覆盖风光/星空/火烧云三大题材 |
| 技术 | 构建可扩展的 Agent 框架，支持工具热插拔、多轮对话、多模态输入 |
| 开源 | 代码开源，文档完善，可供其他开发者参考与贡献 |

### 1.4 文档范围

本文档定义 LightTrail v0.1（MVP）的功能需求、非功能需求与系统架构方向，作为后续设计与开发的基线。不包含详细 UI/UX 设计、API 接口规范与部署运维方案（后续独立文档）。

## 2. 用户画像与使用场景

### 2.1 目标用户

**主要用户：摄影进阶爱好者**

| 特征 | 描述 |
|------|------|
| 技术水平 | 理解曝光三角、会手动模式拍摄、有后期基础，但天文/气象知识有限 |
| 器材 | 拥有可换镜头相机（无反/单反），常用 2-3 支镜头 |
| 题材偏好 | 风光、星空、火烧云等自然题材为主 |
| 痛点 | 拍前不知道去哪拍、拍时参数靠猜、拍后缺乏专业反馈 |
| 使用习惯 | 手机随身，拍摄前 1-3 天开始规划，拍摄中需要快速参考 |

**次要用户：摄影初学者**——需要更多解释与引导，对参数推荐结果的「为什么」更敏感。

### 2.2 典型使用场景

**场景一：星空拍摄计划（提前规划型）**

> 周三晚上，小北想周末去崇明东滩拍银河。他打开光迹说：「这周末想去崇明拍银河，松下 S5M2 + 契卡 14mm，有什么建议？」

光迹需要：
1. 查询本周末的月相、月升月落时间（判断月光干扰）
2. 查询崇明东滩的银河可见时段与方位角
3. 查询天气预报（云量、能见度）
4. 综合 1-3 判断是否适合拍摄，给出推荐日期与时间窗口
5. 基于 14mm 镜头推荐曝光参数（500 法则 / NPF 法则）
6. 生成拍摄计划（出发时间、到达时间、拍摄时间线、备选方案）

**场景二：火烧云即时判断（临场决策型）**

> 晨光初现，小北看到天边有红霞，不确定今天火烧云会不会爆发。他问光迹：「现在上海，火烧云概率大吗？值不值得去拍？」

光迹需要：
1. 获取当前时间与上海位置
2. 查询当前云量、朝霞指数等气象数据
3. 基于经验模型判断火烧云爆发的概率与等级
4. 如果值得拍，推荐附近机位并给出构图建议
5. 如果不值得，给出原因并建议是否等待

**场景三：参数即时推荐（拍摄中辅助型）**

> 在拍摄现场，光线快速变化。小北问：「现在拍日落剪影，f/8、ISO 100，快门该用多少？如果想让前景也亮一些呢？」

光迹需要：
1. 理解拍摄意图（日落剪影 → 大光比场景）
2. 基于曝光经验给出初始参数建议
3. 针对追加需求（前景补亮）给出调整方案（可能涉及包围曝光或 HDR 建议）

**场景四：照片复盘分析（拍摄后改进型）**

> 拍完回家，小北上传一张成片问光迹：「这张拍得怎么样？构图和曝光有什么可以改进的？」

光迹需要：
1. 多模态理解照片内容（场景类型、构图方式、曝光水平、色彩风格）
2. 结合拍摄参数（如有 EXIF）分析技术合理性
3. 给出构图、曝光、色彩维度的评价与改进建议
4. 如果有同场景参考作品，给出对比分析

## 3. 功能需求

### 3.0 功能架构总览

```
LightTrail 智能体
├── Agent 基础能力
│   ├── 多轮对话管理
│   ├── 工具调用与协同
│   └── 系统提示词与角色设定
├── F1 拍摄参数智能推荐
│   ├── 曝光三角换算
│   ├── 星空曝光计算（500/NPF 法则）
│   ├── 长曝光计算（ND 减光）
│   └── 风光场景参数建议
├── F2 机位规划与模拟
│   ├── 位置搜索与天文事件查询
│   ├── 日出日落/银河方位模拟
│   └── 机位推荐
├── F3 摄影计划编排
│   ├── 条件综合评估（天气/月相/潮汐）
│   ├── 拍摄计划生成
│   └── 备选方案与行程提醒
└── F4 照片智能分析
    ├── 多模态画面理解
    ├── 构图/曝光/色彩评价
    └── 改进建议生成
```

### 3.1 Agent 基础能力

**现状**：已完成最小链路（多轮对话 + 工具调用），含 `get_current_time`、`equivalent_exposure` 两个演示工具。

| 编号 | 需求 | 优先级 | 说明 |
|------|------|--------|------|
| A-01 | 多轮对话管理 | P0 | 维护对话历史，支持上下文追踪与历史清空。**已实现**。 |
| A-02 | 工具调用循环 | P0 | 模型返回 tool_calls → 执行 → 回传结果 → 继续推理，最大 8 轮。**已实现**。 |
| A-03 | 工具注册表 | P0 | 装饰器注册、OpenAI schema 自动生成、统一分发与错误处理。**已实现**。 |
| A-04 | 串行 API 调用 | P0 | 模块级锁保证同一进程内不并发请求（平台要求）。**已实现**。 |
| A-05 | LLM 调用容错 | P0 | 限流(429)/服务器错误(5xx)指数退避重试，最多 3 次。**已实现**。 |
| A-06 | 模型路由策略 | P1 | 常规对话/工具调用用 ecnu-plus，深度推理/计划编排用 ecnu-max。按任务复杂度自动选择。 |
| A-07 | Thinking 模式 | P1 | 关键决策（如综合评估拍摄条件）启用 thinking 模式，提升推理质量。 |
| A-08 | 对话持久化 | P2 | 将对话历史存盘，支持跨会话恢复。MVP 阶段可不实现。 |

### 3.2 F1 — 拍摄参数智能推荐

**功能描述**：结合天文/气象数据与用户器材信息，为星空、长曝光、风光等场景推荐曝光参数组合。

#### F1.1 曝光三角换算

**现状**：已实现 `equivalent_exposure` 工具，支持基于档数调整的等效曝光换算。

| 编号 | 需求 | 优先级 | 说明 |
|------|------|--------|------|
| F1.1-01 | 等效曝光换算 | P0 | 给定光圈/快门/ISO + 目标调整档数，输出三种优先方案。**已实现**。 |
| F1.1-02 | 就近取档 | P1 | 将连续计算值就近映射到相机实际档位（光圈 1/3 档、快门 1/2 或 1/3 档、ISO 整档）。当前仅文字提示，后续实现工具化。 |
| F1.1-03 | EV 值计算 | P2 | 引入曝光值（EV）作为场景亮度参考，支持基于 EV 的参数推导。 |

#### F1.2 星空曝光计算

| 编号 | 需求 | 优先级 | 说明 |
|------|------|--------|------|
| F1.2-01 | 500 法则计算 | P0 | 根据镜头焦距与画幅计算星空摄影最大快门速度（不拖线）。公式：500 / (焦距 × 裁切系数)。 |
| F1.2-02 | NPF 法则计算 | P1 | 更精确的星空快门计算，考虑像素间距、光圈、焦距。适用于追求画质的高分辨率传感器。 |
| F1.2-03 | 星空参数组合推荐 | P0 | 综合 500/NPF 法则 + 器材特性（光圈最大值、高感性能）给出光圈/快门/ISO 推荐组合。 |
| F1.2-04 | 月光补偿 | P1 | 根据月相与月光亮度，调整星空曝光参数（满月时需减曝光或缩短快门）。 |

**输入**：镜头焦距（mm）、画幅（全画幅/APS-C/M4/3）、光圈值、ISO、月相（可选）  
**输出**：最大不拖线快门速度、推荐参数组合、计算依据说明

#### F1.3 长曝光计算

| 编号 | 需求 | 优先级 | 说明 |
|------|------|--------|------|
| F1.3-01 | ND 减光换算 | P0 | 给定基准曝光 + ND 滤镜档位，计算长曝光快门速度。例：f/8、1/125s、ISO 100 + ND1000 → 8s。 |
| F1.3-02 | 多档 ND 推荐 | P1 | 根据拍摄意图（丝滑水面/拉丝云层/车轨）推荐合适的 ND 档位与对应参数。 |
| F1.3-03 | 长曝光时机建议 | P2 | 结合光线条件判断长曝光可行性（光太强时需更强 ND）。 |

**输入**：基准曝光参数（光圈/快门/ISO）、ND 档位（或目标效果）  
**输出**：调整后快门速度、参数组合、注意事项（如防抖、遮光罩使用）

#### F1.4 风光场景参数建议

| 编号 | 需求 | 优先级 | 说明 |
|------|------|--------|------|
| F1.4-01 | 场景识别与参数推荐 | P1 | 识别用户描述的拍摄场景（日落剪影/黄金时刻/蓝调时刻/海景慢门），给出参数起点建议。 |
| F1.4-02 | 包围曝光建议 | P2 | 大光比场景推荐包围曝光范围与张数。 |
| F1.4-03 | 超焦距计算 | P2 | 根据焦距、光圈、画幅计算超焦距与景深范围，辅助风光对焦。 |

### 3.3 F2 — 机位规划与模拟

**功能描述**：基于地理位置、地形与光线方向推荐拍摄机位，模拟日出日落、银河方位等构图预览。

#### F2.1 位置与天文事件查询

| 编号 | 需求 | 优先级 | 说明 |
|------|------|--------|------|
| F2.1-01 | 地点搜索 | P0 | 根据用户输入的地名/地标搜索经纬度。可对接地图 API（如腾讯地图）。 |
| F2.1-02 | 日出日落时刻 | P0 | 根据经纬度 + 日期计算日出、日落、黄金时刻、蓝调时刻的精确时间。 |
| F2.1-03 | 银河方位与可见时段 | P0 | 根据经纬度 + 日期计算银河中心升落时间、方位角与仰角。 |
| F2.1-04 | 月相与月升月落 | P1 | 查询指定日期的月相、月升月落时间与方位，评估月光对星空拍摄的影响。 |
| F2.1-05 | 潮汐查询 | P2 | 海岸拍摄场景查询潮汐时间与高度。 |

#### F2.2 方位模拟与构图预览

| 编号 | 需求 | 优先级 | 说明 |
|------|------|--------|------|
| F2.2-01 | 方位角计算 | P1 | 计算日出日落/银河中心相对于拍摄地点的方位角与仰角。 |
| F2.2-02 | 构图预览（文字描述） | P1 | 根据方位角 + 地形信息，以文字描述推荐构图方向与画面元素布局。 |
| F2.2-03 | 可视化方位图 | P2 | 生成方位角示意图（SVG/极坐标图），直观展示天体方位。 |

#### F2.3 机位推荐

| 编号 | 需求 | 优先级 | 说明 |
|------|------|--------|------|
| F2.3-01 | 基于天文条件推荐 | P1 | 根据拍摄题材（银河/日出/日落）与天文事件方位，推荐朝向合适的拍摄地点。 |
| F2.3-02 | 基于地形/可达性推荐 | P2 | 结合地形数据（海拔、遮挡）与交通可达性筛选机位。需接入地形与道路数据。 |
| F2.3-03 | 机位知识库 | P2 | 积累用户标记的优质机位，形成可复用知识库。 |

### 3.4 F3 — 摄影计划编排

**功能描述**：综合天气、月相、潮汐等条件自动生成拍摄计划与备选方案。

#### F3.1 条件综合评估

| 编号 | 需求 | 优先级 | 说明 |
|------|------|--------|------|
| F3.1-01 | 天气数据获取 | P0 | 获取指定地点未来 1-7 天的天气预报（云量、能见度、降水概率、风力）。 |
| F3.1-02 | 拍摄条件评分 | P0 | 综合天文（月相/银河可见性）+ 气象（云量/能见度）+ 潮汐，对指定日期的拍摄可行性打分。 |
| F3.1-03 | 火烧云概率预测 | P1 | 基于云量、朝霞/晚霞指数判断火烧云爆发概率与等级。 |
| F3.1-04 | 条件变化趋势 | P2 | 展示未来数天的拍摄条件变化趋势，辅助选择最佳日期。 |

#### F3.2 拍摄计划生成

| 编号 | 需求 | 优先级 | 说明 |
|------|------|--------|------|
| F3.2-01 | 计划自动生成 | P0 | 根据拍摄目标 + 条件评估结果，生成结构化拍摄计划（含时间线、参数建议、注意事项）。 |
| F3.2-02 | 备选方案 | P1 | 主计划条件不佳时，自动生成备选方案（换日期/换地点/换题材）。 |
| F3.2-03 | 计划导出 | P2 | 支持将拍摄计划导出为日历事件或文本文件。 |

**计划格式示例**：
```
拍摄计划：崇明东滩银河拍摄
日期：2026-08-15（周六）
条件评分：85/100（优）

时间线：
  02:00  出发（预计车程 1.5h）
  03:30  到达，架设器材
  03:45  银河中心升至 15°，开始拍摄
  04:30  最佳拍摄窗口
  05:00  天文晨光开始，银河渐隐
  05:30  收工

参数建议：
  镜头：契卡 14mm f/2.8
  快门：25s（500 法则：500/14 ≈ 35s，保守取 25s）
  光圈：f/2.8（全开）
  ISO：3200（S5M2 高感可控）

注意事项：
  · 月相：残月（5%），月光干扰极小
  · 银河中心方位：东南偏南，仰角 15°-30°
  · 建议带保暖衣物，海边风大

备选方案：
  若 8/15 云量 > 50%，改 8/16（条件评分 78）
```

#### F3.3 行程提醒

| 编号 | 需求 | 优先级 | 说明 |
|------|------|--------|------|
| F3.3-01 | 提醒设置 | P2 | 根据计划自动计算提醒时间（出发前 30min），推送提醒。 |

### 3.5 F4 — 照片智能分析

**功能描述**：利用大模型多模态能力，对成片进行构图、曝光、色彩分析与改进建议。

#### F4.1 多模态画面理解

| 编号 | 需求 | 优先级 | 说明 |
|------|------|--------|------|
| F4.1-01 | 照片上传与识别 | P0 | 支持用户上传照片（JPEG/PNG），调用 ecnu-plus 多模态能力进行画面理解。 |
| F4.1-02 | 场景与主体识别 | P0 | 识别拍摄场景类型（风光/星空/城市/人像等）与画面主体。 |
| F4.1-03 | EXIF 读取 | P1 | 从照片 EXIF 中提取拍摄参数（焦距、光圈、快门、ISO），辅助分析。 |

#### F4.2 分析与评价

| 编号 | 需求 | 优先级 | 说明 |
|------|------|--------|------|
| F4.2-01 | 构图分析 | P0 | 分析构图方式（三分法/引导线/对称等）、主体位置、画面平衡度，给出评价。 |
| F4.2-02 | 曝光分析 | P0 | 结合画面内容与 EXIF 参数，判断曝光是否合理（过曝/欠曝/动态范围），给出调整建议。 |
| F4.2-03 | 色彩分析 | P1 | 分析画面色彩风格、色温倾向、色彩搭配，给出评价与后期方向建议。 |
| F4.2-04 | 综合评分 | P2 | 对照片给出多维度评分（构图/曝光/色彩/创意），量化分析结果。 |

#### F4.3 改进建议

| 编号 | 需求 | 优先级 | 说明 |
|------|------|--------|------|
| F4.3-01 | 改进建议生成 | P0 | 针对分析发现的问题，给出具体的改进建议（如「下次可尝试降低机位，强化前景引导线」）。 |
| F4.3-02 | 参数优化建议 | P1 | 结合 EXIF 与画面效果，推荐下次拍摄可调整的参数方向。 |

## 4. 非功能需求

### 4.1 性能

| 编号 | 需求 | 说明 |
|------|------|------|
| NF-01 | 单轮响应时间 | 纯文本回复 ≤ 10s；含 1 次工具调用 ≤ 15s；含多轮工具调用 ≤ 30s。受平台 API 延迟制约。 |
| NF-02 | 串行调用约束 | 同一进程内 LLM 调用严格串行（平台建议），不并发请求。**已实现**。 |
| NF-03 | 工具执行超时 | 单个工具执行超时 10s，超时后返回错误信息供模型重试。 |
| NF-04 | 对话历史长度 | 单会话消息历史不超过 50 条，超出后自动摘要或截断早期消息。 |

### 4.2 可靠性

| 编号 | 需求 | 说明 |
|------|------|------|
| NF-05 | API 调用容错 | 限流(429)/服务器错误(5xx)自动重试，指数退避，最多 3 次。**已实现**。 |
| NF-06 | 工具异常处理 | 工具执行异常不中断对话，错误信息回传模型供其修正。**已实现**。 |
| NF-07 | 输入校验 | 工具参数类型校验，非法参数返回结构化错误。**已实现**。 |
| NF-08 | 配置缺失兜底 | API Key 缺失时给出明确提示，不崩溃。**已实现**。 |

### 4.3 可扩展性

| 编号 | 需求 | 说明 |
|------|------|------|
| NF-09 | 工具热插拔 | 新增工具只需在 tools/ 下编写模块并注册，不改 Agent 核心代码。**已实现**（装饰器注册）。 |
| NF-10 | 模型可切换 | 支持通过环境变量切换模型（ecnu-plus / ecnu-max），不改动代码。**已实现**。 |
| NF-11 | 数据源可替换 | 天文/气象数据源通过接口抽象，可替换为不同 API 提供商。 |
| NF-12 | 多画幅支持 | 曝光计算工具支持全画幅/APS-C/M4/3 等常见画幅的裁切系数。 |

### 4.4 安全与隐私

| 编号 | 需求 | 说明 |
|------|------|------|
| NF-13 | API Key 保护 | 密钥仅存于本地 .env 文件，不写入代码仓库，不上传至 LLM 上下文。 |
| NF-14 | 用户数据不出域 | 对话历史与上传照片仅本地处理，不上传至第三方服务（LLM 平台除外）。 |
| NF-15 | 敏感信息过滤 | 系统 Prompt 中不包含用户隐私信息。 |

## 8. 术语表

| 术语 | 说明 |
|------|------|
| 曝光三角 | 光圈、快门速度、ISO 三者共同决定曝光量，调整其一需补偿其余 |
| EV（曝光值） | 衡量场景亮度的对数标度，EV = log₂(N²/t)，N 为光圈值，t 为快门速度（秒） |
| 500 法则 | 星空摄影经验法则：最大快门速度 ≈ 500 / (焦距 × 裁切系数)，超过则星星拖线 |
| NPF 法则 | 更精确的星空快门计算法则，考虑像素间距与光圈 |
| ND 滤镜 | 中性密度滤镜，均匀减少进光量，用于长曝光 |
| 黄金时刻 | 日出后/日落前约 1 小时，光线柔和温暖 |
| 蓝调时刻 | 日出前/日落后约 30min，天空呈深蓝色调 |
| 天文晨光/暮光 | 太阳位于地平线下 18° 的时刻，此后天空完全黑暗（天文晨光始 = 银河拍摄结束时间） |
| 裁切系数 | 相对全画幅（36×24mm）的焦距等效倍数：全画幅 1.0，APS-C 约 1.5，M4/3 约 2.0 |
| 火烧云 | 日出日落时天空出现的红色/橙色霞光，由大气散射形成 |
| Thinking 模式 | ECNU 平台模型的思考模式，通过 `thinking: {"type": "enabled"}` 开启，模型在回答前进行推理 |
| Tool Calling | OpenAI 兼容接口的函数调用能力，模型返回结构化工具调用请求，由应用执行后回传结果 |
