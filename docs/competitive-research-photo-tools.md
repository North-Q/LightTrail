## 0. 调研说明

### 0.1 目的

为光迹的架构重建与功能演进建立竞品坐标系：

1. 验证「数据 → 决策」的差异化定位是否成立（市面上是否已有「给决策」的摄影工具）；
2. 梳理各赛道工具的功能面，标记对光迹 D1–D4 / M1–M2 有参考价值的功能点；
3. 识别潜在威胁：哪些工具正在向「决策」进化，窗口期还有多久。

### 0.2 方法与信息源

- **一手来源**：各工具官网 / 官方文档 / 应用商店页面（功能面以此为准）；
- **二手来源**：媒体报道（腾讯新闻、周到上海、齐鲁晚报、湖北日报）、垂直社区（NGA、什么值得买、巡星客、图虫教程）、评测站（marlvel.ai、FilterPixel / Aftershoot 官博、Unstar 差评分析）、LiveScience 的 AI 摄影助手一周实测；
- **小红书**：本轮未做站内直连（浏览器远程调试未开启），采用搜索引擎索引内容 + 媒体转述 + 社区转载的二手信息，相关结论已标注「小红书生态观察」；待小北开启浏览器调试后可补一轮站内直连调研。

### 0.3 参考价值评级标准

| 评级 | 含义 |
| --- | --- |
| ★★★★★ | 核心竞品：功能面与光迹主线高度重叠，必须深度拆解 |
| ★★★★ | 重点参考：某功能模块对光迹有直接借鉴意义 |
| ★★★ | 局部参考：个别功能点或设计思路可借鉴 |
| ★★ | 了解即可：知道存在、清楚边界即可 |
| ★ | 暂不参考：与光迹方向无关 |

## 2. 分类详述

### 2.1 综合摄影规划类（直接竞品核心）

#### 2.1.1 PhotoPills ★★★★★

- **背景**：西班牙 PhotoPills S.L.，iOS/Android 双端，美区 $10.99 一次性买断；App Store 约 4.7 分 / 2k 评价，付费榜多市场 Top 10。
- **功能点**：
  - 2D 地图 Planner：放置机位图钉，查任意日期/时间的日、月、银河方位角与高度角；支持地形阴影模拟（某时刻阳光照亮哪座山）；
  - Night AR / 日间 AR：现场把手机对准环境，叠加银河位置、银心方位、太阳月亮轨迹——踩点确认的核心交互；
  - 金色/蓝色时刻 Planner：精确到 GPS 位置的时刻表 + 全天光强彩色曲线（不只告诉开始时间，还告诉优质光线窗口持续多久）；
  - 日月 Planner：在地图上沿弧线拖动月亮，反查「月亮正好挂在某建筑上方」的日期与机位；
  - 银河 Planner：银心可见窗口逐小时位置 + Bortle 光污染等级；
  - Spot Stars 星轨模拟：设定曝光时长，预览星轨形态（北向绕北极星画圆 / 南向扫弧线）；
  - 计算集群：DoF/超焦距、曝光/ND、星空 500 法则、延时摄影、日食月食 Planner、Drone 模式（含飞行高度取景）；
  - 其他：Plans/机位保存复用、桌面 Widget 速览今日关键时刻、PhotoPills Awards（应用内摄影赛事，奖金至 $6,600）。
- **口碑**：功能价值获一致认可；**学习曲线陡峭是最大抱怨**（53/53 条近期评价分析的高置信结论）；更新节奏为「维护级」（曾 104 天无更新，仅修 bug 与新增相机型号）；AR + GPS 耗电高。
- **对光迹的参考**：D2 规划的交互标杆。Plans 保存复用是 M1 记忆的单机雏形；Widget 速览是 D3 临场轻量入口的形态参考；AR 现场验证对应 D2 踩点环节。
- **与光迹的边界**：给数据不给决策；无天气融合（规划完了还得自己去别处看云）；无个性化（不知道你的器材和偏好）；无复盘。

#### 2.1.2 PlanIt! Pro（巧摄）★★★★★

- **背景**：美籍华人乔文杰（JIDE Software, Inc.）开发；专业版约 ¥38 买断，3D 模型等高级能力另有订阅（约 ¥7/月）；有专门中国版（内置高德地图 + 离线数据）；iOS 美区 4.9 分 / 8.5k 评价。
- **功能点**（在 PhotoPills 基础上更全）：
  - 天体精度 0.1°：日、月、银河、星座、星云位置，曙暮光/黄金/蓝调时段，日食月食；
  - **机位 × 主体双点几何**：地图上设拍摄点与主体点，自动计算两点距离、海拔差、方位角、仰角——悬日悬月类题材的数学内核；
  - **四种虚拟取景框**：VR / AR / 图片 / 街景，叠加星历信息模拟真实构图，主体高度可手动输入；
  - 3D 地形与建筑遮挡模拟（全球高程数据 + 城市 3D 建筑）；
  - 星轨规划、延时计算与动画模拟、序列计算、银河搜索；
  - 长尾天象：**彩虹位置预测**、潮汐高度与潮汐搜索（部分国家）、流星雨；
  - 曝光/ND 计算器、测光表、焦距/视角/DoF/超焦距、全景与航拍规划；
  - 全离线：离线海拔文件 + 离线 mbtiles 地图 + 离线星历，野外无网可完整规划；
  - 计划保存为项目（时间/地点/坐标/预期效果），可分享导出。
- **对光迹的参考**：功能面天花板。双点几何模型是 D2「机位 × 天象匹配」可直接复用的数学内核；四种取景框是 D2 可视化的形态清单；彩虹/潮汐提示光迹工具扩展的长尾方向。
- **与光迹的边界**：同样是「数据 + 模拟」，决策仍靠人；功能密度带来的学习成本被普遍提及；无记忆、无个性化、无复盘。

#### 2.1.3 极摄 ★★★★★

- **背景**：上海极摄信息科技有限公司，iOS/Android 双端，**全功能免费**；采用高德地图 + 中科星图等国内合规地理数据；2025–2026 年活跃迭代（彗星面板、AR 彗星等跟随天文热点）。
- **功能点**：
  - **悬日悬月机位计算（核心招牌）**，双模式：**按时间找机位**（今天天气好，附近哪有可拍的机位）/ **按机位搜时间**（已知某机位能拍某建筑悬月，反查可拍日期）；
  - 3D 场景模拟：官方建筑模型库 + 用户自建模型 + 红色靶心任意点设拍摄对象 + 离地高度修改（解决「环金穿月」这类对齐点不在建筑上的情况）；
  - 取景框时间轴：拖动时间滑块看月亮/太阳轨迹，微调机位至天体恰好「悬」在目标位置；
  - 太阳/月亮/银河/流星雨/彗星轨迹模拟，AR 彗星 + 拍彗星参数建议；
  - 卫星地图视角展示用户作品，陌生城市快速定位拍摄点；
  - **漫步地球社区**：拍摄计划、机位、模型、作品可分享，订阅/点赞/赞赏机制，定期摄影比赛；
  - App 内直接导航至规划机位。
- **口碑**（小红书生态观察）：悬日题材社区公认「绝大多数人起步首选」（免费 + 官方建筑建模），与巧摄（数据最全、功能最细）和 PhotoPills（出国拍摄更顺）形成三分格局；社区同时提醒「软件算出的机位只代表天文几何成立，现场树挡/能否站人要自己踩」。
- **对光迹的参考**：D2 机位 × 天象匹配的最直接国产竞品。**双向搜索（时间→机位、机位→时间）是 D2 的核心交互范式**；自建模型 UGC 是机位知识库共建的思路；拍摄计划可分享对应光迹方案分享。
- **与光迹的边界**：无天气融合（悬日「天气一票否决」要用户自己看云量）；无个性化记忆；无决策输出——它回答「在哪拍、何时拍」，不回答「值不值得去」。

#### 2.1.4 Sun Surveyor ★★★

- $9.99 买断（另有 Lite 免费版）；Live View AR 流畅易上手，交互地图 + 街景模式（不去现场也能查对齐）。
- **参考价值**：多篇评测的共识是「PhotoPills 90% 的功力、10% 的学习成本」——这是光迹 UX 的对标点：**决策引擎的输出必须比数据工具更轻，否则打不过「够用就好」的 Sun Surveyor**。

#### 2.1.5 TPE（The Photographer's Ephemeris）★★★

- Web + iOS + Android；免费基础版 + Pro 订阅（3D 地形）；地图派而非 AR 派：俯视角展示光线如何与地形互动（山影如何扫过山谷）。
- **参考价值**：桌面 + 移动同步（在家规划、现场查看）的工作流分层；地形阴影分析的思路。
- **口碑佐证**：用户踩坑案例——只看 AR 不看地形，被第二道山脊挡住光线，说明**单一数据源规划存在系统性盲区，多源交叉（光迹的路线）有真实价值**。

#### 2.1.6 Sunlitt / Shadowmap / Sun Seeker / SunQuest ★★

- Sunlitt：Apple 生态精品太阳追踪（AR + Shadow Map + 地形阴影）；Shadowmap：城市 3D 阴影分析（建筑/地产/机位遮挡）；Sun Seeker/SunQuest：通用太阳路径。了解边界即可。

### 2.2 天象与气象预报类（数据源竞品）

#### 2.2.1 莉景天气 ★★★★★

- **背景**：开发者李召麒（清华美院工业设计，清华摄影队、前清华天文协会成员，为国家天文/国家地理供图）；2017–2018 年人工预报朝霞晚霞并发布方法论文章，2018–2019 年实现算法自动化，微信小程序起家后扩展 APP；**国内风光摄影圈渗透率最高**。
- **功能点**：
  - **朝霞/晚霞预报：概率 + 质量双指标**。概率 = 周边 100km 内发生概率（综合云图、能见度、光照条件计算云底是否会变红）；质量 = 本地云量/云高/能见度综合（如果有霞，云够不够多、够不够红）。官方强调两者不可互换；
  - 柱状图可视化：柱高 = 概率，柱色 = 质量；
  - 云海预报：精确到「哪个山头几点在云海之上」；
  - 彩虹、雾凇预报；平流雾查询；
  - 观星指数（整晚云量 + 能见度 + 月相）+ 光污染地图（选暗夜机位）；
  - **5 日逐小时云分层**（对比 windy/meteoblue 仅逐 3 小时，且有外网访问问题）；
  - EC + GFS 双模式 + 光追算法；
  - 金色/蓝色时刻、天文晨光始/昏影终、日月出落、全天光位圆盘图（粉色扇形 = 蓝调窗口、深蓝扇形 = 拍星最佳时段）；
  - **附近晚霞机位**推荐；
  - **「预见」社区**：摄影生活记录、心得交流、作品分享。
- **算法思路**（开发者公开）：晚霞 = 本地云底被照亮；光路上不能有云、雾霾、水汽、沙尘挡光；结合日出日落时间方位 + 卫星云图预报 + 云底高度 + 能见度做光路空间 3D 计算。
- **口碑**：「摄影圈人手一个」；北京角楼高概率日人山人海、箭扣长城云海预报日用户聚会；开发者自己声明「容错率好的用户能大幅提高出片命中率，容错率差的可能不适合」；NGA 用户评价「要付费，几块钱，还挺准」。
- **对光迹的参考**：D3 临场赌注决策的最直接数据源竞品。① 概率 + 质量二维分离是置信度表达的成熟范式（光迹 DecisionCard 可借鉴）；② 火烧云判据（云底照亮 + 光路无遮挡）是规则层可复用的领域知识；③ 附近晚霞机位是 D2×D3 联动的雏形；④ 预见社区是 D4 内容沉淀的形态参照。
- **与光迹的边界**：给概率不做「去/不去」决策（「80% 以上毫不犹豫出发」是用户自发规则，不是产品输出）；无机位个性化（不知道你在哪、有什么机位）；预报失误时没有依据链解释（M2 的空间）。

#### 2.2.2 天文通 ★★★★★

- **背景**：福州触梦科技有限公司；APP（iOS/安卓全渠道）+ 微信小程序 + 公众号；**全平台累计安装 300 万+**；免费为主；迭代活跃（星空识别已至 v1.9，彗星/月食功能紧跟天文热点）。
- **功能点**：
  - 观星指数预报：综合云量、透明度、视宁度、空气质量、月相、光污染，**多模型逐小时对比** + 15 日夜间天气；
  - **星空识别**：拍一张夜空照片，本地解析真实星座、亮星、深空天体（照片 → 星区反推）；
  - 真实模拟星图：星座、地平遮挡、真实地形、卫星、银河、AR 中心指向、取景框；
  - 地图规划：光污染（Bortle）、晴夜率、日夜范围、日月银河规划图层叠加；
  - 目标规划与天空模拟：未来 15 夜目标高度、云量、观测窗口；
  - **天空条件目标推荐：根据天空条件推荐行星、深空天体和近期天象——「今晚看什么」**；
  - 3D 月球（月相/月食模拟/月面地标/月食地图）；
  - 卫星（中国空间站实时位置与过境预报）、流星雨日历（极大/流量/月光影响/观测提示）、极光预报（KP/Bz 变化 + 条件转好提醒）；
  - 天文摄影工具：取景框、相机与望远镜视场、马赛克规划、等效焦距、导星精度、红灯模式；
  - 每日天文美图。
- **对光迹的参考**：① 「目标推荐」已摸到 D1 主动决策的边缘（今晚看什么）——**但它不知道你拍过什么、有什么器材、在哪，是无个性化推荐；光迹要做的是带 M1 记忆的个性化版本**；② 星空识别（照片 → 星区）对 D1 照片反推有技术路线参考；③ 观星指数的多因子合成方法可直接借鉴；④ 取景框/马赛克规划是星空工具组的扩展方向。
- **与光迹的边界**：推荐无个性化；无「去不去 / 去哪」的出门决策（它告诉你能看什么，不告诉你值不值得跑 50km 去看）；无复盘闭环。
- **威胁评估：高**。团队迭代快、用户基数大、产品形态最接近光迹的星空部分。

#### 2.2.3 SunsetBot ★★★★

- **背景**：免费网页（sunsetbot.top）+ 同名微信小程序；数据源为 NCEP-GFS（每日 4 更）、ECMWF（中东部每日 4 更）、CAMS（气溶胶与霾）。
- **功能点**：
  - **火烧云鲜艳度指数（0–2.5+）**：综合持续时间、亮度与颜色饱和度、云量（格点云量/云相态/含水量）、占天空面积、云底高度与层间遮挡、AOD；九级命名从「微微烧」到「世纪大烧」（0.4 以上可考虑出门、1.0 以上值得专程跑、1.5 以上可遇不可求）；
  - AOD 气溶胶光学厚度（大气通透度，决定颜色鲜艳程度）；
  - **ERA-5 经典案例再分析回放**：查看历史上大烧/小烧/污烧/水晶烧在预报图上的形态，帮助用户学习读图；
  - **烧/污散点图**：散点越上越「污」、越右越「烧」——不确定性的可视化表达。
- **口碑**：NGA「预测有烧基本就是有，大小不一定准」；上海乍浦路桥火烧云热搜事件中，媒体直接引用其数值（0.047 = 微烧）作为权威依据。
- **对光迹的参考**：D3 火烧云赌注的**量化范式**参考。与莉景「概率 + 质量」双指标是两种不同的可解释性设计路线（单指数分级 vs 双指标分离），值得并案评估；散点图的不确定性可视化、历史案例回放（复盘数据集思路）对 M2/D4 都有借鉴。
- **与光迹的边界**：纯数据输出，无机位、无决策、无个性化。

#### 2.2.4 SkyCast / FollowSun ★★

### 2.6 AI 拍摄助手类（形态最接近光迹）

#### 2.6.1 通用 LLM 助手（ChatGPT / Claude 等）★★★★★（形态参照 + 反面对照）

- **关键实证**（LiveScience 一周实测，2026）：
  - 规划：直接喂坐标会定位出错需人工纠正；视角、焦距、时间窗建议基本合理且可交叉验证；**价值定位是「快速首查 + sense-check」（判断这个拍摄值不值得投入详细规划），不能替代专业规划 App**；
  - 参数建议：技术正确但**系统性保守**（安全快门 + 保守 ISO）；会给出推理过程（加分项）；**无法基于创作意图**——它不知道你愿不愿意为决定性瞬间接受噪点；
  - 天气解读：最有前景的用法——不是呈现预报，而是**解释为什么这些条件重要**，并清单化（带什么、注意什么）；
  - 幻觉风险贯穿始终。
- **行业观察**（barnimages 2026）：摄影师已普遍用 ChatGPT 做 shot list、客户邮件、社媒文案等**事务性工作**，但「数据精确性」场景通用 LLM 吃不动。
- **对光迹的意义**：这是光迹存在意义的最有力论证——通用 LLM 的三大缺口（**数据幻觉 → 光迹工具取数 + M2 数据透明；无记忆 → M1；无意图理解 → M1 档案 + 偏好**）正是光迹的地基。同时它的「解释型天气解读」验证了 D3 决策输出的内容形态（不是给数字，是给「这意味着什么、该怎么做」）。

#### 2.6.2 WayShot ★★★

- iOS（2025-08 上线，一个月进摄影榜 Top 200）；自称「世界首个 AI 摄影师」；实时取景检测 → 构图/姿势/表情/角度语音引导；AI 修图（光影平衡/皮肤质感/背景清理/电影感）；免费 + 订阅。

#### 2.6.3 Klick ★★

- AI 相机助手，实时取景构图反馈（数千张专业照片训练）。了解即可。

#### 2.6.4 LensMentor ★★★

#### 2.6.5 Doka 相机 ★★★

- **对光迹的参考**：D4 复盘的最直接形态参照。**AI Coach「找反复弱点」= 光迹 D4 + M1 联动（处方累积成个人成长档案）的国际版验证**；EXIF 驱动点评上下文的做法可直接复用（光迹 D4 读 EXIF 判断参数合理性）。

#### 2.6.8 Savvy Capture ★★★★（AI 照片点评子类）

- Android，免费 + 内购；照片点评（分数 + 待修项 + 类别反馈 + 重拍计划）+ **最佳照片选择（2–5 张对比排名 + 各维度理由）** + 拍摄计划生成（主体 → 概念/光位/机位/构图/起始参数/首拍清单）+ Pose 教练 + **重拍对比（原片 vs 重拍：改进了什么、还差什么、下一次重拍计划）** + Mentor Progress 进步追踪。
- **对光迹的参考**：**重拍对比闭环（拍 → 评 → 重拍 → 验证进步）是 D4 复盘闭环的直接形态参照**；拍摄计划生成（主体 → 完整方案）与光迹 D1 一句话出方案同构，可对比其输出结构。

#### 2.6.9 PhotoMentor ★★★（AI 照片点评子类）

- Web + Chrome 扩展 + Telegram bot 三端同步；自动识别 30+ 摄影类型并按类型加权评分；构图准则叠加标注（三分法/引导线/视觉平衡）+ Pro 版边界框瑕疵标注。
- **参考价值**：类型加权评分（不同题材不同评判权重）的思路，对应光迹的题材感知（火烧云/星空/蓝调各自的复盘维度）。

### 2.7 后期与复盘 AI 类

#### 2.7.1 FilterPixel ★★★★

- 桌面工作流 + 云端处理；$19.99/月。
- **DeepCull 类型感知选片**：选婚礼/运动/会议/音乐会等题材，AI 按该题材的评判标准选片（运动看动作峰值/球员面部清晰/球在画面内；会议看演讲者状态/观众反应/标牌可读性）；
- **Score+Reason 透明化：每张图给数值分数 + 自然语言理由**（「92 分——眼部对焦清晰、构图强、表情峰值」/「34 分——主体运动模糊、闭眼、存在更高分重复帧」）；
- 云端处理与本地硬件解耦（1000 张约 3 分钟）；眨眼/模糊/重复帧检测；LR/C1 一键导出。
- **对光迹的参考**：**M2 可解释性的最佳实践——「分数 + 理由」正是光迹 DecisionCard 的雏形**；类型感知对应光迹题材感知。
- **对 D4 的启示**：选片决策的用户接受前提是「理由可核查」——D4 处方同理。

#### 2.7.2 Aftershoot ★★★

- 本地处理（隐私卖点）+ 全自动选片 + 修图一体；$14.99/月；**个人 AI profile：学习你的选片/修图偏好**——这是 M1 个性化在后期域的形态验证；One-Click Cull + Edit 一键跑完选片 + 修图。

#### 2.7.3 Narrative Select ★★

- LR 插件；AI 辅助（标记模糊/闭眼/场景分组）但**每个最终决定都留给人**——与 Aftershoot 全自动路线形成对照。
- **对光迹的启示**：自动化 vs 辅助化路线之争在选片域已有充分实践。光迹 D4 定位建议：处方是辅助（给建议 + 依据），最终判断留给人——这与「决策引擎」不矛盾，DecisionCard 本身就是「建议 + 依据链」而非强制执行。

#### 2.7.4 Imagen AI / Photo Mechanic / Lightroom AI ★★

- Imagen：按张付费云端 AI 修图（个人风格学习）+ 选片附加；Photo Mechanic：无 AI 手动选片速度标杆（$149/年，证明「快」本身有付费价值，AI 不是必选项）；Lightroom Assisted Culling（2026）：Adobe 原生人脸眼部评分——大厂入场信号。

## 3. 竞争格局分析

### 3.1 赛道全景（数据 → 决策 × 单点 → 全旅程）

| 象限 | 玩家 | 特征 |
| --- | --- | --- |
| 纯数据 · 单点 | Windy、Meteoblue、晴天钟、计算器类 | 给原始数据/指数，自己解读 |
| 数据 + 模拟 · 多环节 | PhotoPills、巧摄、极摄、天文通、莉景 | 规划/预报强，但「去不去」留给用户 |
| 摸到决策边缘 | 天文通目标推荐（今晚看什么）、SunsetBot 指数分级（媒体解读出「0.4 出门 / 1.0 值得跑」阈值）、莉景概率（用户自发形成「80% 出发」规则） | 数据里已隐含行动建议，但产品不输出决策 |
| 决策 · 单点 | AI 相机类（取景框内构图决策）、FilterPixel（选片决策 + 理由） | 有决策形态，但仅限单一环节 |
| **全旅程 + 决策 + 个性化** | **空位 —— 光迹** | 无一直接竞品 |

### 3.2 光迹的三个空位验证

1. **个性化记忆（M1）**：全场仅 Aftershoot 个人 AI profile（后期域）和 Evalens AI Coach（点评域）沾边；**规划/决策域无人做**——所有工具都不记得你是谁、拍过什么、有什么器材。
2. **可解释决策（M2）**：FilterPixel Score+Reason 证明「分数 + 理由」可行且被用户接受；莉景概率 + 质量、SunsetBot 散点图是数据级解释；**没人做决策级解释**（为什么建议去/不去，依据链可溯源）。
3. **全旅程闭环（D1–D4）**：单点工具各自为战；复盘与规划从不回链（Evalens 不知道你拍那天的火烧云概率是多少、天气预报说了什么）；**光迹 D4 处方 → 反哺 D1–D3 决策改进，是全场唯一闭环**。

### 3.5 商业模式对比与口碑警示

**定价谱系**：买断制（PhotoPills $10.99、Sun Surveyor $9.99、巧摄 ¥38）→ 订阅（TPE Pro、AI 选片类 $10–20/月、巧摄 3D 模型 ¥7/月）→ 免费 + 会员（莉景）→ 全免费（极摄、SunsetBot、天文通基本盘）。

**口碑大数据警示**（Unstar 2026 年修图类 App 差评分析，可类推到工具类）：

1. **35% 的一星差评指向订阅墙 / 免费功能缩水**（「以前免费的功能现在锁了」「每点两下就弹升级」）——全行业最高发的怨念；
2. **AI 功能名不副实是第二大雷区**（「广告里的 AI 完美无缺，我用的像用剪刀剪的」）；
3. 导出质量缩水、云同步丢数据、大文件性能崩溃跟随其后。

**对光迹的启示**：

1. 开源（MIT）+ 可小额付费的路线在「订阅疲劳」大环境下本身就是差异化叙事；
2. **AI 能力宣传不要超过实际能力**——M2 可解释性不只是产品理念，也是防「AI 名不副实」反噬的工程设计（给依据链 = 让用户能验证）；
3. PhotoPills「买断 + 慢更新」被用户接受良好——工具型产品不必高频迭代，**准确性 > 新功能**；
4. 学习曲线是规划类工具的共同软肋（PhotoPills 最大抱怨）——**光迹用自然语言交互绕开这个坑，是体验层的结构性优势，必须在 Demo 中放大**。

## 4. 结论与建议

1. **「数据 → 决策」的空位确认存在**：本次调研覆盖的 38 个工具中，无一做到「全旅程 + 决策 + 个性化」。光迹的产品定位成立，且差异化支柱（M1 记忆 / M2 可解释 / D1–D4 闭环）各自都有「全场仅见雏形、无人做透」的证据支撑。
2. **窗口期不会永远开着**：天文通（目标推荐）、极摄（免费扩张）、字节可颂（平台流量）三个方向都有向决策进化的可能。建议 B6/B7 之后优先做深 **D3 临场决策 + M1 记忆**——这是工程壁垒最高、最难被快速追赶的两块（预报算法可以买，个性化记忆的数据飞轮买不来）。
3. **火烧云预报赛道已拥挤**（莉景 / SunsetBot / SkyCast / FollowSun / 天文通 + 小红书博主生态），光迹不做「更好的预报」，做「更好的用预报」——结合用户机位、器材、历史命中率给出个性化赌注建议，预报失误时用 M2 依据链兜底解释。
4. **下一步建议**：
   - 对五个 ★★★★★ 工具（PhotoPills / 巧摄 / 极摄 / 莉景 / 天文通）做深度功能拆解（可单独立项，逐个产出拆解笔记）；
   - 小红书站内直连调研待浏览器调试开启后补一轮，重点验证「追霞博主」内容形态与用户对「人肉决策」的真实反馈；
   - 评估 SunsetBot 量化指数思路：D3 是接入其数据源、还是参考其判据自建火烧云规则层（光迹已有火烧云领域知识，可结合 Windy 分层云判据做 v1 判据集）；
   - Evalens 的 EXIF 驱动点评 + FilterPixel 的 Score+Reason 可作为 D4 / M2 的原型参考，建议在 B6 设计评审前各做一次 hands-on 体验。
